# Fitness Tracker reference documents

This folder holds preserved research, audits, exploration plans, and past implementation notes. `activity-model-history/` records older activity-model work, `split-classifier/` is a self-contained classifier research package, and `retained-root-copies/` preserves former root copies.

Current app behavior and decisions are in [`STATUS.md`](../STATUS.md), with the active site and service worker at the project root. The documents here are reference material; they are not all current implementation requests.
