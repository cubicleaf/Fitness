# Fitness Tracker files

`index.html` is the offline-first app; `sw.js`, `assets/`, `api/`, and `seed-data.csv` support it. Read `INTENT.md` for purpose and `STATUS.md` for current decisions and open work. The current related-activities and onboarding contracts are `FAMILY-SYSTEM-AND-PICKER-SPEC.md` and `TOUR-SPEC.md`.

`_docs/` holds supporting reference. Its `activity-model-history/` folder preserves earlier modeling proposals; `retained-root-copies/` preserves former root duplicates of the existing `data-model.md` and `user-flows.md`. `_archive/` holds older app/seed artifacts. `my real data/` is separate from the demo seed data. Historical images and versions remain in their existing folders, including `old images/`.
